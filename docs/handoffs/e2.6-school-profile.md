# Handoff → Frontend: E2.6 — School profile (details, logo, principal's signature)

> Backend status as of 2026-10-14. Contract: `contracts/openapi.json` (run `npm run api:types`).

## What exists now
- The school's details are now editable data instead of server config:
  - name, motto, address, phone, email, website and the principal's name.
  - On first start-up the old `School` config values are copied in, so nothing changes until the admin edits them.
- **Report cards (PDF) use the profile:**
  - The header shows the name, motto, address and contacts.
  - The uploaded **logo** replaces the built-in crest; with no upload, the crest is used.
  - The **principal's signature** image prints in the principal's comment box, above their name.
- **Images:**
  - JPEG, PNG or WebP, up to 12 MB.
  - Re-encoded server-side to **PNG with transparency kept**, at most 600 px. EXIF and any other payload are stripped.
- **Who sees what:**
  - The logo is **public**: `GET /api/public/school/logo`, so the website and login page can show it.
  - The signature is **admin-only**, since a signature image could be misused if copied.

## Endpoints
| Method & path | Who | Body → Response | Errors |
|---|---|---|---|
| `GET /api/school/profile` | Admin, Teacher, Bursar | → `SchoolProfileDto` | 401, 403 |
| `PUT /api/school/profile` | Admin | `{ name, motto?, address, phone?, email?, website?, principalName? }` → `SchoolProfileDto` | 400 (`name`, `address`, `email`, …), 403 |
| `PUT /api/school/profile/logo` | Admin | multipart field `file` → `SchoolProfileDto` | 400 `errors.file`, 403 |
| `DELETE /api/school/profile/logo` | Admin | → `SchoolProfileDto` | 403 |
| `PUT /api/school/profile/signature` | Admin | multipart `file` → `SchoolProfileDto` | 400, 403 |
| `DELETE /api/school/profile/signature` | Admin | → `SchoolProfileDto` | 403 |
| `GET /api/school/profile/signature` | Admin | `image/png` (private cache) | 403, 404 |
| `GET /api/public/school/logo` | anyone | `image/png` (private cache) | 404 when none uploaded |

```ts
type SchoolProfileDto = {
  name: string; motto: string | null; address: string; phone: string | null; email: string | null;
  website: string | null; principalName: string | null;
  logoVersion: string | null; signatureVersion: string | null; // append ?v= to image URLs; null = none uploaded
};
```
Notes on the save call:
- `PUT /profile` replaces all text fields.
- Blank optional fields are stored as null.
- Name (≤ 120) and address (≤ 300) are required.
- Email is checked for a valid format.
